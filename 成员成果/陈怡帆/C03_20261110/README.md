取数步骤：

1. 从项目共享来源表 S10—S13、S16 定位发布机构官网或正式PDF，按城市、机构、业态、统计期搜索。区分报告统计期与发布日。
2. 在同一报告的对应城市和业态段落核对绝对值、计价单位和指标定义。有原件就保存原始字节、检索时间与SHA256。官网可读但未留原件的，逐条保存URL和定位记录。
3. 以「机构×城市×业态及等级×指标定义×频率」建序列。JLL与高力即使都写净有效租金，仍分开记录；原文环比文字原样保留（仅清理小数内空格），不按四舍五入值反算。
4. 高力官网正文与下载表单分开登记。未提交表单；表单HTML不算报告原件。中指付费预览只列取得状态；其AI摘要没有进指标表。缺期保持空白，不用预测值、插值或其他机构指标填补。

这批数据是城市或市场板块指标，按 C03 独立成表，不填假资产ID，也不并入 B01/B02 逐标的交易表。适用于同类市场的趋势参考；没有具体租约或物业条件时，不能作为融通单项目租金或实收。
