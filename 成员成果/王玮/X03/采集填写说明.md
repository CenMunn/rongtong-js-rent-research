# 第一阶段采集填写说明

王玮整理，2026年11月8日，版本1.0。字段依据原工作簿“字段字典”，保留统一采集表的28个字段。资料见[共享目录](../../../共享资料/)。

每行表示一处明确出租范围的一次价格观察。同一物业历次公告、不同资产包和不同价格性质分别保留观察，独立资产数与观察数分别统计。原件保留，整理结果记录版本和来源。

| 字段 | 填写要求 |
| --- | --- |
| asset_id、observation_id | 明确范围采用稳定资产ID，每次观察ID唯一；暂编ID标依据，与席风翔的主表核对 |
| round_contract_id | 保留官方场次、资产包或合同号；临时关联号标明含义 |
| lessor_entity、rongtong_relation | 出租法人、管理或发布关系分别记录并附证据，未知留空并写原因 |
| use_legal_actual、address_scope_floor | 合法、实际和招商用途加标签分开写，地址包含楼栋、楼层、房号和整分租范围 |
| area_building_chargeable_land | 建筑、计租和土地面积分别加标签及单位，一项一行；原文明确为0才填0，未知留空 |
| price_type、raw_price_unit | 底价、挂牌、合同、成交、估值、市场指标、面议或无价分别标记，原金额、单位及费用原文保留 |
| publish_sign_start_end_dates | 发布、成交、签约、起租、到期加标签，只填披露日期，租期另写原文 |
| collection_date | 填实际采集日期和时间，推荐ISO格式并含+08:00时区 |
| related_party | 按证据填非关联、关联或未核 |
| tax_fee、rent_free_escalation、lease_incentive | 含税、税率、费用承担、免租、递增、补贴和改造责任分别记录，缺失注明原因 |
| monthly_normalized | 有明确原价和面积时列名义月单价及公式，标建筑或计租面积分母 |
| effective_rent | 完整取得租约经济条款后按实际现金流计算，注明口径；资料不足留空并说明 |
| coordinates_crs、accessibility、building_condition、industrial_specs | 有可靠资料可填，注明坐标系、测量方法或参数来源，未知继续留空 |
| market_series_id、poi_time_license | 写引用系列、环境资料的日期、定义、来源和使用条件，尚未采集时说明状态 |
| source_url_page | 写精确原文URL、附件名、物理页码或图序；本地原件补共享位置并标原出处状态 |
| verification_status、comparison_decision、missing_reason | 写清已提取、待核或具体已核字段，纳入或剔除理由另列，缺失写未披露、未取得、不适用或待核 |

复合字段采用“标签=值及单位”的逐行写法。例如真实记录WX-20261108-000001保存底价7.21万元/年、年价72100元、建筑面积560㎡，其名义建筑月单价为72100÷12÷560，约10.729167元/建筑㎡/月。这个例子用于说明填写与换算，原表的出租主体、计租面积等待核状态继续保留。

无价、面议、仅项目条件及单位无法确认的记录继续保留。金额可空，价格性质和缺失原因写清。原文未披露租金不等同采集失败。
