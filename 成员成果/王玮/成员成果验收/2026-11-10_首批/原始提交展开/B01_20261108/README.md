## 关键限制与发现

1. 中山北路285号采用成交对应“-4”轮次的210.90㎡。不得用其他轮次的面积替代。
2. 苏州公交首末站项目找到了2024年5月同编号挂牌，面积480㎡。本次证据不依赖2024年12月不同编号的挂牌。
3. 北区1—9号：批量公告的标的列表把铺号对应到N0117FCZZ250441—250449；同一公告所附清单提供逐铺面积；成交公示再次核对编号、铺号和金额。扫描件的项目编号栏写“以系统提示为准”，因此必须保留标的列表这一步证据。
4. 湖南路2024年项目公告总面积1547.66㎡，其中575㎡存在迟延交付安排，先交付部分972.66㎡。所列月单价只按公告总范围名义分摊；实际计租、交付和免租须由B03继续核查。
5. 湖南路2023年项目公告约6300㎡，同时说明负一楼约500㎡不计产证面积。两者包含关系与实际计租分母仍需核对合同，月单价保持为空，不自行加减500㎡。
6. 北区1—8号折算单价相同，不是算法填充：逐条原成交金额及逐铺面积分别读取后得到相同结果。9号成交810202元，高于底价387595.32元，保留二者差异。
7. 公告面积不自动认定为建筑面积或实际计租面积。未取得的税费、实际合同起止、实际收款、有效租金、关联关系等字段留空或说明待核。原件中有明确条款的仅作提示，未替代B03完整合同核验。
