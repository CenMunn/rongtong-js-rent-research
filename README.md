提交时将本人数据、原文或附件定位、获取方法和问题记录放入自己的成员目录，说明对应任务编号和本次变化。CSV与Excel可下载后查看和填写，CSV保存为UTF-8编码。王玮维护[任务台账](分工与进度/任务台账.csv)，收口字段、版本和阶段成果。文件位置见[文件索引](分工与进度/文件索引.csv)。

采集时保留原价、原单位、日期、出租范围和来源，分别标记底价、挂牌、合同、成交及无价线索。同一资产历次价格观察保留，以资产ID和观察ID关联。公众号底表当前有1157行，包含机器提取、无价及待核记录；外部交易明细有47行，具体价格性质和核验状态见表内说明。

首次使用代码可阅读[运行说明](代码/README.md)。大批原图、网页存档和较大PDF通过共享位置交接，在文件索引及数据来源字段记录链接。
