# 公众号数据整理

王玮维护，对应Y01。仅依赖Python标准库，将已核实的5项修订和2项差异说明落实到公众号底表副本，并输出逐字段修改日志和版本哈希。

这是当前7项核实结果的限定版本整理程序，不是通用OCR纠错器。输入底表须匹配已核实的1157行版本；程序会核对原值、观察ID及证据原图哈希，不匹配时停止。

从仓库根目录运行，结果默认保存在 `成员成果/王玮/Y01/公众号整理版_v1/`：

```powershell
python "代码/公众号数据整理/build_reviewed.py"
```

该版本目录已发布，重复运行会拒绝覆盖。需要复跑时指定新的空目录；仍是相同规则的v1复跑，后续新增修订需要另行更新规则版本。

```powershell
python "代码/公众号数据整理/build_reviewed.py" --out "成员成果/王玮/Y01/公众号整理版_v1_复跑"
```

程序默认读取共享公众号底表、Y01七项核实记录和证据索引；可用 `--source`、`--evidence`、`--evidence-index` 指定同版本文件的位置。

输出包括28字段整理CSV、逐字段修改日志、版本清单和版本说明。原始底表不改，行序和两类ID保留，不去重、不删历史观察。对中山东路金额和常熟土地面积分别保留双来源及待核状态，不强选采用值。原OCR片段保留时仍可能触发格式检查提示，具体当前结论见复核说明。

检查程序与测试：

```powershell
python -m unittest discover -s "代码/公众号数据整理/tests" -v
```

7项测试读取已有真实底表，只将派生结果写入临时目录，验证行列与ID、5项修订、两项差异、其余记录不变、日志覆盖和禁止覆盖版本。测试结果不增加采集样本数。

入口：[整理版说明](../../成员成果/王玮/Y01/公众号整理版_v1/版本说明.md)、[七项核实说明](../../成员成果/王玮/Y01/Y01_七项建议核实说明.md)。

## 整理版v2

`python "代码/公众号数据整理/build_reviewed_v2.py"` 接续v1，按第二批10条成员签核结果生成v2；默认输出目录已发布，复跑请用 `--out` 指定新空目录。保留原始底表和v1，输出本批/累计修改日志、签核与依据快照、两项未定差异和版本哈希。原值对照时仅等价化CSV换行，不改写历史值；累计日志可从原始底表回放。v2不将全表标为人工已核，不推定正式金额。详见[版本说明](../../成员成果/王玮/Y01/公众号整理版_v2/版本说明.md)。
