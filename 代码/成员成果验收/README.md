# 成员成果验收

维护人王玮。`review_first_batch.py`为2026-11-10固定首批材料的复核脚本，读取陈怡帆B01/B02原包并安全展开，核B02证据哈希、10条金额/原单位/披露分母/名义换算，记录跨编号配对与重复候选，并对B01做结构和明示算术初查。依赖Python及beautifulsoup4（`python -m pip install beautifulsoup4`）。

从仓库根目录执行 `python "代码/成员成果验收/review_first_batch.py" --out "成员成果/王玮/成员成果验收/新的空目录"`。默认正式目录已发布，不可覆盖；新输出目录建议位于本仓库内，便于证据相对定位。

事实预期来自本次阅读存档正文，不是通用自动审核模型，不因数值或ID匹配就认定最终可比。脚本不实时逐页回网，不发送信息，不自动合库或代成员签核。10条算术相符中1条成交分母仍属跨编号条件接收；未得到的合同、有效租金和关联关系不补值。收件汇总说明和协调台账由王玮按实际文件单独维护。

复跑不会改成员原包或共享表，输入哈希写入运行记录；报错生成的未完成目录不能当作验收通过成果。正式输出见[验收与材料汇总说明](../../成员成果/王玮/成员成果验收/2026-11-10_首批/验收与材料汇总说明.md)。
