使用方法
在 Windows 上安装 Python 和 Edge 或 Chrome，双击“按片区合集采集.cmd”，粘贴融通地产江苏公司的微信合集链接并回车。首次运行自动安装依赖。每个合集的结果按合集 ID 保存于 outputs/公众号片区采集/合集ID/交付文件。
程序分页核对账号与总篇数，筛选标题，逐篇存档，按原文分项目和资产包，导出正文价格。遇到微信验证可在新打开的窗口完成；仍未取得正文时，逐篇清单保留失败状态，可重跑同一链接。
原样保留同一物业的各次发布，包括日期或金额不同的报价。合集归属以来源为准，项目城市以实际地址为准。文章未披露底价也保留正文和项目线索。
重点查看“挂牌底价总表.csv”与“逐篇采集清单.csv”。正文明确转引且能定位的表图自动下载并做 OCR。其他未提取字段可留空，不影响整批采集。若需录入图片价格，在合集ID目录的“人工核图.csv”对照原图填单位、金额、标的范围并将状态设为“已核”，同图多个标的可增加行；重跑汇入总表。首次运行产生的未确认图片金额留在图片复核清单，不会作为确认年租金。
