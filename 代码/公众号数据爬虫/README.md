# 公众号采集程序

维护人为王玮。

Windows 下安装 Python 和 Edge 或 Chrome，双击 `按片区合集采集.cmd`，粘贴公开的微信公众号合集链接。首次运行会建立本地 Python 环境并安装依赖。

程序取得合集目录、筛选相关文章，保存正文及来源，整理项目、报价与图片基本情况表。运行中如出现微信验证，按打开页面的提示完成后继续。

结果默认写入本目录下的 `outputs/公众号片区采集/合集ID/`。`交付文件` 保存整理结果，`项目基本情况表` 子目录包含项目行、特别说明、单元格及筛查记录。原文和候选原图由各批次的存档目录留存。

图片识别结果附有待核状态，核对金额时同时查看表头单位、标的范围及特别说明。网页取得成功、OCR提取成功、人工核验分别记录。

命令行方式可从仓库根目录进入本程序目录，安装依赖后运行合集入口。

```powershell
cd "代码/公众号数据爬虫"
python -m pip install requests beautifulsoup4 playwright lxml pillow pymupdf "rapidocr-onnxruntime==1.2.3"
python wechat_album.py "公众号合集链接"
```

这些程序取自当前项目已使用的版本。不同电脑的 Python、浏览器及微信访问状态可能影响运行结果，出现问题时记录运行命令、版本、日志和失败链接，提交到本人目录供排查。
