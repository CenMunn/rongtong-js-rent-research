# 数据质量检查

王玮维护，X03初版版本1.2；仅依赖Python标准库。程序读取原28字段CSV，原数据不被覆盖，生成规则、逐条结果、问题明细、人工复核清单及摘要。

从仓库根目录检查本批真实样例，选择新的结果目录：

```powershell
python "代码/数据质量检查/check_data.py" --input "成员成果/王玮/X03/2026-11-09_首批样例/统一填写样例_真实9条.csv" --template "共享资料/统一采集空表.csv" --out "成员成果/王玮/X03/自行检查_新批次"
```

不传参数时仍沿用共享公众号底表及旧X03目录；该目录已填写复核意见，程序将阻止覆盖，因此推荐明确传入--input与新的--out。

支持年总租÷12÷面积、月总租÷面积、原文直接平方米月价。金额须和原价字段的数值及单位对应，面积须和建筑/计租/披露标签对应；其他表达保留待核。直接元/间/月不得当平方米月价；无价允许金额留空，零建筑面积可保留但不作分母。同资产多期允许，重复观察ID报错。

文件结构错误、错误记录和待核记录分别汇总。文件缺列/重复表头不能解释为通过。网址仅查文本格式；来源真实性、页面可达性和计租范围仍需原件核对。V01表示原表仍有待核事项，不代表金额必错。算术通过也可能存在OCR源值错误。

输出目录如已有填入原件值、结论、建议、复核人或日期的人工复核清单，程序会在任何写出之前停止。改用新目录，保留旧意见。

运行合成边界测试：

```powershell
python -m unittest discover -s "代码/数据质量检查/tests" -v
```

tests仅放程序合成用例，非真实数据，不计入采集样本。依赖输入文件是仓库原28字段空表。
