# 数据质量检查

维护人王玮，对应X03任务。程序使用Python标准库，读取统一采集CSV，生成问题与人工复核清单。

从仓库根目录运行。

```powershell
python "代码/数据质量检查/check_data.py"
```

默认输入为 `共享资料/公众号采集结果.csv`，字段依据 `共享资料/统一采集空表.csv`，结果写入 `成员成果/王玮/X03/`。运行前先拉取最新数据，运行后检查结果再提交。

指定其他批次时使用以下参数，路径相对于当前命令行目录。

```powershell
python "代码/数据质量检查/check_data.py" --input "待检查.csv" --template "共享资料/统一采集空表.csv" --out "检查结果目录"
```

五份输出为逐条质检结果、问题明细、人工复核清单、质检规则及质检摘要。规则表由程序生成，包含检查范围和默认级别。人工复核清单提供原件值、结论、修正建议、复核人和日期空列。先处理优先项，再开展代表样例复核。

输入SHA256在运行前后核对。原始数据保留，无价项目可留空金额，零建筑面积可保留，观察ID重复与同资产多期分别处理。金额和面积表达不清时记录待核，原文不被自动覆盖。

当前规则针对中文复合字段，只校验明确写出的年租金÷12÷面积公式，按显示精度检查舍入。其他公式继续保留待核。来源为离线文本检查，网络、图片数字、主体及计租范围仍需原件核对。V01表示原表还有待核事项，可能涉及金额以外的字段。

详见[采集填写说明](../../成员成果/王玮/X03/采集填写说明.md)。
