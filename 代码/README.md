# 代码目录

各项程序按功能建立独立子文件夹，相关脚本、启动器和运行说明集中存放。

| 程序 | 维护人 | 内容 |
| --- | --- | --- |
| [公众号数据爬虫](公众号数据爬虫/) | 王玮 | 公众号文章、合集、租金及项目基本情况表采集，含图片文字识别 |
| [数据质量检查](数据质量检查/) | 王玮 | CSV字段、ID、单位、日期及明示公式的离线检查，生成问题和人工复核清单 |
| [公众号数据整理](公众号数据整理/) | 王玮 | 根据已核实证据生成公众号整理副本、逐字段修改日志和版本清单，保留原始底表 |

后续新增代码使用清楚的功能名称建立子文件夹，在文件夹内附README，写明维护人、用途、依赖安装、运行入口及结果保存位置。成员提交时注明对应任务编号与本次变化。
